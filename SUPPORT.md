# Support

The [README](README.md) identifies the Reader, review Atlas, and maintenance skill separately and explains how to open each artifact.

For a broken link, missing artifact, or reproducible display problem, use [GitHub Issues](https://github.com/refat247/Cradle_Rx/issues). Include the artifact and version, device and browser, reproduction steps, and expected and actual behavior. Use synthetic examples.

Keep patient information, medical records, prescriptions and other private evidence out of public issues. GitHub Issues is for repository maintenance. Clinical decisions and urgent concerns belong with the responsible clinical team. For a suspected security issue, use a private reporting channel only if the repository's Security tab offers one.
